    Ejemplos con curl
    
    
    Sustituye $HOST por la URL de tu despliegue.
    
    
    # 1) Subir un archivo local
curl -s -X POST "$HOST/v1/analyze" -F "file=@foto.jpg" | jq '.verdict, .risk_score'

# 2) Analizar una URL remota
curl -s -X POST "$HOST/v1/analyze" \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://ejemplo.com/foto.jpg"}' | jq

# 3) Con perfil estricto y respuesta censurada
curl -s -X POST "$HOST/v1/analyze?strictness=strict&censor=true" -F "file=@foto.jpg" | jq

# 4) Imagen en base64
curl -s -X POST "$HOST/v1/analyze" \
  -H 'Content-Type: application/json' \
  -d "{\"image_base64\":\"$(base64 -w0 foto.jpg)\"}" | jq

# 5) Lote de URLs (fallos individuales no abortan el lote)
curl -s -X POST "$HOST/v1/analyze/batch" \
  -H 'Content-Type: application/json' \
  -d '{"urls":["https://a.com/1.jpg","https://b.com/2.jpg"]}' | jq '.summary'

# 6) Con autenticación
curl -s -X POST "$HOST/v1/analyze" -H "X-API-Key: $NID_API_KEY" -F "file=@foto.jpg" | jq

    Integración recomendada
    
    
    Patrón típico para impedir subidas indebidas sin degradar la experiencia.
    
    
    POST /v1/analyze  (antes de escribir en S3 / tu BD)

verdict == "allow"   -> guarda la imagen
verdict == "review"  -> guárdala en cuarentena y encola moderación humana
verdict == "block"   -> rechaza con 4xx y registra {request_id, sha256, risk_score}
    
    
    
      Privacidad: la API no persiste imágenes ni las escribe en disco; solo se registra el
      sha256, el veredicto y las etiquetas. Las URLs se registran sin query string para no
      filtrar tokens firmados. Aun así, revisa tu base legal antes de procesar imágenes de usuarios:
      un detector de desnudos es tratamiento de datos sensibles en muchas jurisdicciones.
    
    
    
    
      Límites conocidos: ningún clasificador visual es infalible. Espera falsos positivos en
      playa/piscina, arte clásico, lactancia o contenido médico, y falsos negativos con desnudos
      parciales, ilustraciones o imágenes muy pequeñas. Por eso la API devuelve tres veredictos y no
      un simple sí/no: el intervalo review existe para que un humano decida los casos dudosos.
